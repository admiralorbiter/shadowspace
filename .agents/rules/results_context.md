# Rule: Rich Execution Results & Contextual Summaries

Whenever completing experiment runs, commits, or research audit milestones:
1. **Detailed Context & Manifest Metrics**: Provide key quantitative metrics, edge diagnostics, status breakdowns, and manifest JSON snippets directly in responses.
2. **Commit & Sync Status**: State the exact code SHA, results SHA, git status, and remote branch sync status.
3. **Reproducibility & Verification**: Include precise test counts, command outputs, parameter configurations, and next-step recommendations to ensure smooth review and context tracking.
