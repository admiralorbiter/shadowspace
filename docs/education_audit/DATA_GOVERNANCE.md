# Data Governance & Privacy Policy - Educational Counterfactual AI Audit

---

## 1. Data Classification

All data used in this repository fall strictly under **Synthetic Public Research Data**.

- **No FERPA-Protected Records**: No real student names, grades, transcripts, essays, or educational records are stored, processed, or submitted.
- **No PII**: No Personally Identifiable Information of any individual is used.
- **Synthetic Profile Generation**: All base student profiles are artificially generated fact sheets.

---

## 2. API & Vendor Terms Compliance

- All LLM API queries must be conducted under approved developer/research terms.
- No inputs containing private user data will be transmitted.
- All prompt texts and model outputs are logged with SHA-256 content hashes for provenance verification.
