Panel 01 · Model Recovery

How Much Neighborhood Structure Do Models Recover?

How Does M̂m Compare With the Paired Human Reference H̄?

This task is called Natural Language Inference (NLI). Given a premise — say, "A woman is running" — and a hypothesis — "Someone is exercising" — annotators vote on whether the hypothesis is entailed, neutral, or contradicted.

Each item becomes a point defined by its three-label distribution. The score asks whether a model and an independent human cohort place the same items in the same local neighborhoods. Compare the nine model scores with the paired human reference and the empirical identity-permutation null.

Fully paired estimand: M̂m = (1/1000)·Σb Mm,b, where both Hb and Mm,b are evaluated against identical posterior-predictive cohorts (GH1(s), GH2(s)). Point estimates are focal-bootstrap means; 95% bootstrap intervals shown for Δm.

Panel 02 · Stability Analysis

What Happens When Candidate Neighbors Are Tied?

How Does Storage-Index Tie Resolution Affect Fixed-k Neighborhoods?

To measure how similar two groups' opinions are, we find the "nearest neighbors" of each item — the other sentence pairs that are most similar in how people disagreed about them. Think of it as asking: which sentences in the dataset are closest relatives of this one, based on how voters reacted?

When multiple candidates share the boundary distance, an index-resolved implementation must choose which candidates enter a fixed-size neighborhood. The tested implementation resolves that choice using storage order. Reindex the demonstration and compare its selected neighbor with the fractional boundary representation.

When multiple candidates share the exact k-th boundary distance, index-resolved methods select by storage order, producing unstable neighborhood graphs. Q̄hard = 0.955 ± 0.0015 at k=10 under random row permutation. The fractional soft statistic QNXsoft is provably invariant to any permutation: Qsoft = 1.000 ± 0.000.

What Do the Stratified Focal-Item Bootstrap Intervals Show?

The paired difference Δ compares the human reference with each model under the same posterior-predictive cohorts. The interval chart shows variation from resampling focal-item overlap contributions within the fixed ChaosNLI candidate population.

This procedure does not rebuild the candidate set or neighbor graphs from each resample. It estimates focal-item sampling variation conditional on those precomputed graphs; shared graph edges also make contributions non-independent.

Appendix · Exploratory Finding
Exploratory question: do identical vote profiles share explanation-validity structure? VariErr External Validation (Study 2B) — Exploratory / Inconclusive

Exploratory · Study 2B 500 matched items 52 multi-item profiles
Do items with the same ChaosNLI vote distribution also have similar explanation-validity profiles in VariErr? This tests whether a Level-1 vote pattern carries information about a Level-2 property.

Across 52 multi-item vote profiles, within-profile validity variation was 7.8% below the profile-size-preserved permutation null mean. The empirical permutation result was p=0.2045, so the analysis is statistically inconclusive. Matched 500 items across 52 multi-item annotator profiles from the VariErr external dataset. Within-profile SD = 0.106 vs. permutation null mean = 0.115 (7.8% reduction, 25% below overall SD). Permutation p-value = 0.2045 across 500,000 permutations. Inconclusive: consistent with either a small signal or sampling limitations of the 52-profile restriction.
