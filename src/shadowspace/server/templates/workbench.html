💡 Shadowspace Quick Reference Guide

What is Shadowspace?

Shadowspace is an interactive visualization tool for exploring high-dimensional model belief distributions (like 10-class softmax probabilities). Because 10D data cannot be directly drawn on a 2D screen, linear PCA projection squishes space down—which can introduce geometric distortions.

Integrity X-Ray Links & Glowing Halos

  • 🟢 Preserved Neighbors (Green): True neighbors in both high-dimensional space AND 2D projection. The 2D map is truthful here.
  • 🔴 Torn Neighbors (Red Dashed): True high-dimensional neighbors that got pulled apart by 2D projection. The red dashed lines show where your real neighbors were dragged to.
  • 🟡 False Neighbors (Yellow Dotted): Fake neighbors that look close in 2D only because space was squished on top of unrelated items.
